### VERSION 1.0.0 IS HERE!

## Intro

[BA Navigator](https://ba.hellolin.top/) is a utility for the mobile game **Blue Archive**, it includes guides & tips categorized by community.

Here you can find detailed guides about students, events, raids, etc.

## Usage

```shell
$ # Clone the repo
$ git clone https://github.com/VLTHellolin/BlueArchiveNavigator.git --depth 1
$ # Install dependencies
$ pnpm install
$ # Start a local server
$ pnpm dev
$ # Get static files
$ pnpm build
```
